# Приложение admin_central (Централизованная админ-панель)
## Назначение
Приложение admin_central предоставляет унифицированный интерфейс администратора Django для управления всеми сущностями системы. Оно интегрирует справочники, сотрудников, лесное хозяйство, складской учёт и техпроцессы в единую панель управления с удобной навигацией.

## Бизнес-ценность
Единая точка управления — все справочники и записи системы доступны в одном интерфейсе
Быстрый поиск и фильтрация — администратор может легко находить и редактировать любые записи
Централизованное управление доступом — создание и управление сотрудниками с автоматической синхронизацией пользователей
Контроль данных — просмотр и редактирование любых записей без необходимости писать код
Автоматическая синхронизация — при создании сотрудника автоматически создаётся пользователь Django

## Ключевые возможности
### Управление справочниками (core)
Должности — создание и управление должностями
Склады — просмотр и редактирование складов
Транспортные средства — управление автопарком
Контрагенты — ведение базы контрагентов с ИНН и ОГРН
Бригады — управление бригадами

### Управление сотрудниками (employees)
Создание и редактирование сотрудников с привязкой к должности и складу
Автоматическая синхронизация с пользователями Django (для руководящих должностей)
Управление паролями через административную панель
Учёт рабочего времени — просмотр и редактирование записей
### Управление лесным хозяйством (forestry)
Материалы — справочник материалов (древесина, ГСМ, запчасти)
Лесничества — управление лесничествами
Лесосеки — управление лесосеками с привязкой к лесничествам
Содержание лесосек — просмотр материалов на каждой лесосеке
### Управление складским учётом (inventory)
Места хранения — просмотр всех мест хранения с названиями источников
Движения материалов — полный просмотр и фильтрация всех движений
Остатки материалов — просмотр актуальных остатков
### Управление техпроцессами (operations)
Типы операций — управление справочником техпроцессов
Записи операций — просмотр и редактирование учёта операций

core — администрирование всех справочников
employees — управление сотрудниками и учётом времени  
forestry — управление лесным хозяйством  
inventory — управление складским учётом  
operations — управление техпроцессами  

## Особенности реализации
Автоматическая синхронизация пользователей — при создании или обновлении сотрудника с руководящей  
должностью автоматически создаётся или обновляется пользователь Django.   
Это обеспечивает единую точку управления доступом.    
Расширенная форма сотрудников — поле пароля добавлено в форму создания сотрудника для удобства управления доступом  
Настройка отображения — каждая модель имеет настроенные списки полей, фильтры и поиск для быстрой работы  
Безопасность — доступ к админ-панели имеют только пользователи с флагом is_staff (синхронизируется с руководящими должностями)  
Единая точка входа — все модели собраны в одном интерфейсе с интуитивной навигацией  

## Синхронизация сотрудников и пользователей
При создании сотрудника с должностью из списка руководящих (Руководитель, Бухгалтер, Механик, Мастер ЛПЦ, Мастер ДОЦ, Мастер ЖД):  
Автоматически создаётся пользователь Django с логином employee_{id}  
Пароль задаётся через форму создания сотрудника  
При деактивации сотрудника пользователь автоматически блокируется  
При изменении данных сотрудника данные пользователя синхронизируются
