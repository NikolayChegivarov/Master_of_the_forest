# Приложение authorization (Авторизация и ролевой доступ)
## Назначение
Приложение authorization обеспечивает вход в систему, разграничение прав доступа и управление   
пользовательскими сессиями. Оно является точкой входа в систему и определяет,   
какой интерфейс увидит пользователь в зависимости от своей должности.   
Также реализован механизм временного переключения между должностями для руководителя.

## Бизнес-ценность
Единая точка входа — все пользователи входят через единую страницу авторизации
Ролевая модель — каждый сотрудник видит только свой интерфейс с доступными функциями
Гибкость управления — руководитель может временно переключаться на интерфейсы подчинённых
Безопасность — строгое разграничение доступа на основе должности
Удобство — автоматическое перенаправление на нужный дашборд после входа

## Ключевые возможности
### Аутентификация
Вход с выбором сотрудника из списка
Автоматическое определение должности и перенаправление на соответствующий дашборд
Безопасный выход с очисткой сессии
### Ролевые интерфейсы
Руководитель — полный доступ ко всем разделам, возможность переключения на интерфейсы подчинённых  
Бухгалтер — доступ к остаткам и движениям материалов всех должностей  
Мастер леса — управление лесничествами, лесосеками, материалами, складами, движениями  
Мастер ЛПЦ — управление лесоперерабатывающим цехом  
Мастер ДОЦ — управление деревообрабатывающим цехом  
Мастер ЖД — управление железнодорожным транспортом  
Механик — управление транспортными средствами  

### Переключение между интерфейсами (для руководителя)
Временный вход в интерфейс любой подчинённой должности
Сохранение оригинальной должности в сессии
Возврат к своему интерфейсу одной кнопкой

## Ролевая модель
Должность   	Доступные функции
Руководитель	Все разделы, переключение на интерфейсы подчинённых
Бухгалтер	    Остатки и движения материалов (всех должностей)
Мастер леса	    Лесничества, лесосеки, материалы, склады, движения
Мастер ЛПЦ	    Лесоперерабатывающий цех
Мастер ДОЦ	    Деревообрабатывающий цех
Мастер ЖД	    Железнодорожный транспорт
Механик	        Транспортные средства

## Интеграция с другими приложениями
core — использует справочник должностей (Position) и сотрудников  
employees — сотрудники используются для входа в систему  
inventory — бухгалтерский доступ к остаткам и движениям  
forestry — доступ мастеров к лесному хозяйству  
operations — доступ к учёту операций  

## Особенности реализации
Вход по сотруднику — аутентификация выполняется через выбор сотрудника из списка, а не через ввод логина и пароля
Хранение данных в сессии — должность, имя и ID сотрудника сохраняются в сессии для быстрого доступа
Автоматическое перенаправление — после входа пользователь сразу попадает на свою панель управления
Режим переключения — флаг is_switched в сессии указывает, что руководитель работает в режиме подмены
Восстановление оригинальной должности — при возврате руководитель получает свой интерфейс без перезагрузки страницы
