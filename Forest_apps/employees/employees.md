# Приложение employees (Сотрудники и учёт рабочего времени)
## Назначение
Приложение employees обеспечивает управление кадровым составом предприятия и учёт рабочего времени сотрудников. Оно позволяет вести базу сотрудников, привязывать их к должностям и складам, а также фиксировать отработанные часы для анализа загрузки персонала.

## Бизнес-ценность
Централизованный кадровый учёт — единая база сотрудников с привязкой к должностям и складам
Контроль рабочего времени — фиксация отработанных часов для анализа производительности
Прозрачность загрузки — отчёты по сотрудникам и складам показывают распределение рабочего времени
История изменений — все записи имеют привязку к создателю и должности
Интеграция с другими модулями — сотрудники используются в складских операциях (водители, мастера)

## Ключевые возможности
### Управление сотрудниками
Создание и редактирование карточек сотрудников
Привязка к должности и складу
Поиск по фамилии, имени, отчеству, должности
Активация и деактивация сотрудников
Детальный просмотр информации о сотруднике
### Учёт рабочего времени
Фиксация отработанных часов с привязкой к дате, складу и сотруднику
Гибкая фильтрация по датам, сотрудникам, складам
Отчёты по сотрудникам за период (с детализацией по дням)
Отчёты по складам за период (с группировкой по сотрудникам)
Подсчёт итоговых часов
### Отчётность
Отчёт по сотруднику — детальная разбивка по дням с указанием отработанных часов
Отчёт по складу — суммарная статистика по всем сотрудникам на складе
Статистика за сегодня — количество сотрудников и отработанных часов

## Ролевая модель
Действие	            Руководитель	Мастер
Просмотр сотрудников	Все	            Свои
Создание сотрудников	Да            	Да
Редактирование сотрудников	Да	        Свои
Активация/деактивация	Да	            Свои
Просмотр учёта времени	Все	            Свои
Создание записей времени	Да	        Да
Редактирование записей	Да	            Свои
Отчёты по сотрудникам	Да	            Свои
Отчёты по складам	Да	                Свои

## Интеграция с другими приложениями
core — сотрудники привязаны к должностям (Position) и складам (Warehouse)
inventory — сотрудники используются как водители в движениях материалов
authorization — сотрудники связаны с учётными записями пользователей

## Особенности реализации
Гибкий учёт времени — поддерживает дробные часы (например, 1.5 часа)
Отчёты по периодам — возможность выбирать произвольный диапазон дат
Группировка по дням — детализация рабочего времени по каждому дню
Привязка к должности создателя — сотрудники и записи времени видны только своей должности
Короткое имя — автоматическое формирование (Фамилия И.О.) для компактного отображения
