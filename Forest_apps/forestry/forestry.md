# Приложение forestry (Лесное хозяйство)
## Назначение
Приложение forestry обеспечивает управление лесным фондом предприятия. Оно позволяет вести учёт лесничеств,   
лесосек и материалов, а также отслеживать наличие древесины на каждом участке.   
Это основа для планирования заготовки и учёта лесных ресурсов.

## Бизнес-ценность
Прозрачность лесного фонда — централизованный учёт всех лесничеств и лесосек с привязкой к должностям
Контроль заготовки — отслеживание количества и видов материалов на каждой лесосеке
Планирование работ — актуальная информация о доступных ресурсах для планирования лесозаготовок
История изменений — фиксация всех действий с указанием ответственного сотрудника
Гибкая номенклатура — единый справочник материалов с поддержкой трёх типов: древесина, ГСМ, запчасти

## Ключевые возможности
### Управление лесничествами
Создание и редактирование лесничеств
Поиск по названию
Фильтрация по статусу (активные / неактивные)
Активация и деактивация лесничеств
Сортировка: активные записи отображаются выше

### Управление лесосеками
Привязка к конкретному лесничеству
Указание номера квартала и выдела
Фиксация площади участка (в гектарах)
Добавление материалов на лесосеку с указанием количества
Редактирование и удаление материалов
Просмотр содержимого лесосеки
Фильтрация по лесничеству, статусу и поиск по адресу

### Управление материалами
Создание единого справочника материалов (древесина, ГСМ, запчасти)
Уникальность комбинации (тип + название)
Фильтрация по типу материала
Поиск по названию

## Интеграция с другими приложениями
inventory — материалы из справочника используются в складском учёте (остатки, движения, конвертации)
core — используется справочник должностей для разграничения доступа

## Особенности реализации
Сортировка активных записей выше — в списках лесничеств и лесосек активные объекты всегда отображаются вверху для удобства работы
Единый справочник материалов — все материалы централизованы и используются как в лесном хозяйстве, так и в складском учёте
Уникальность материалов — запрещено создание дублей (тип + название)
Уникальность лесосек — одна лесосека не может быть создана повторно в том же лесничестве с теми же номером квартала и выдела
