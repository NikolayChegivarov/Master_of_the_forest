# Приложение inventory (Управление складскими запасами)
## Назначение
Приложение inventory является ядром складского учёта системы. Оно обеспечивает полный цикл управления материалами: от поступления на склад до списания, перемещения и реализации.

## Основные сущности
1. StorageLocation (Место хранения)
Универсальная модель для хранения информации о любом месте хранения материалов:
Склады (склад) — стационарные складские помещения
Транспортные средства (автомобиль) — материалы, находящиеся в транспорте
Бригады (бригады) — материалы, переданные бригадам
Контрагенты (контрагент) — материалы, переданные внешним контрагентам
Каждое место хранения привязано к соответствующей сущности через source_type и source_id.

2. MaterialBalance (Остатки материалов)
Хранит актуальные остатки материалов по каждому месту хранения:
Количество в штуках (quantity_pieces)
Количество в погонных метрах (quantity_meters)
Количество в кубических метрах (quantity_cubic)
Автоматическое обновление даты последнего изменения
Обеспечивает уникальность пары (место хранения + материал).

3. MaterialMovement (Движение материалов)
Документирует все операции с материалами. Поддерживает четыре типа движений:

Тип     	Описание	                                Особенности
Перемещение	Перемещение между своими местами хранения	Выполняется сразу, только между своими складами
Отправление	Отправка со своего склада на чужой	        Требует подтверждения получателем
Реализация	Продажа контрагенту	                        Требует указания цены, доступна только руководителю
Списание	Списание материалов на бригаду или ТС	    Только ГСМ и запчасти
Каждое движение содержит:
* Дату и время
* Отправителя и получателя
* Материал и количество
* Водителя и транспортное средство (опционально)
* Номер вагона (опционально)
* Цену и сумму (для реализации)

4. Conversion (Конвертация древесины)
Специализированный документ для переработки древесины:
Списание исходного материала (например, бревна)
Создание целевого материала (например, доски, брус)
Работает только с материалами типа "древесина"
Выполняется мгновенно с обновлением остатков

5. Receipt (Поступление материалов)
Документ, фиксирующий приход материалов на склад:
Дата поступления (можно указать прошедшую дату, до 7 дней)
Склад получатель
Источник поступления (контрагент)
Количество в трёх единицах измерения
Цена и сумма
Автоматическое создание или обновление остатков

## Ключевые возможности
### Управление остатками
Просмотр остатков с фильтрацией по складу, типу материала, материалу
Скрытие пустых остатков
Детальный просмотр каждого остатка
Подсчёт итогов по трём единицам измерения
### Движения материалов
Создание движений с динамической валидацией в зависимости от типа
Автоматическая проверка наличия материалов на складе
Подтверждение отправлений получателем
Редактирование и удаление с ограничением по времени (5 дней для мастера)
Фильтрация по типу, дате, статусу, водителю
Подсчёт статистики по всем движениям
### Конвертация древесины
Создание конвертации с выбором склада, исходного и целевого материала
Автоматическое списание исходного и создание целевого материала
Редактирование с откатом и повторным применением
Удаление с восстановлением остатков
Права доступа: руководитель может редактировать любые, мастер — только свои (до 5 дней)
### Поступления материалов
Создание поступления с выбором даты (до 7 дней назад)
Привязка к контрагенту как источнику
Автоматическое обновление остатков
Редактирование и удаление (мастер — до 5 дней, руководитель — всегда)
### Ролевая модель
Действие	Руководитель	Мастер леса
Просмотр остатков	Все	Свои склады
Создание поступлений	Да	Да
Создание реализации	Да	Нет
Создание отправления	Да (со своих складов)	Да
Создание перемещения	Да	Да
Создание списания	Да	Да
Создание конвертации	Да	Да
Редактирование движений	Любые (кроме выполненных отправлений)	Свои (до 5 дней)
Удаление движений	Любые (кроме выполненных отправлений)	Свои (до 5 дней)
Редактирование поступлений	Любые	Свои (до 5 дней)
Удаление поступлений	Любые	Свои (до 5 дней)
### Технические особенности
Сервисный слой (services.py) для централизованной логики доступа к местам хранения по должности
API эндпоинты для динамической загрузки данных в формах
Автодополнение при поиске материалов
Выделение строк в таблицах с сохранением состояния в localStorage
Три знака после запятой для всех количественных значений
Валидация остатков при создании и редактировании движений
