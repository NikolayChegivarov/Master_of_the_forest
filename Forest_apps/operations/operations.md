# Приложение operations (Управление техпроцессами)

## Назначение
Приложение operations предназначено для учёта технологических операций (техпроцессов), выполняемых на складах и производствах. Оно позволяет фиксировать выполненные работы с указанием объёмов и отслеживать статистику.

## Бизнес-ценность
Приложение позволяет:
    Вести учёт производственных операций
    Анализировать загрузку производственных мощностей
    Отслеживать объёмы переработки материалов
    Формировать отчётность по выполненным работам
    Контролировать эффективность технологических процессов

## Ключевые возможности
### Управление типами операций
Создание новых типов операций
Редактирование существующих
Активация/деактивация типов
Фильтрация по названию и статусу
Статистика по количеству активных и неактивных типов

## Основные сущности
1. OperationType (Тип операции)
Справочник типов технологических операций:
Название операции (распиловка, сушка, строгание, сортировка и т.д.)
Статус активности (можно деактивировать неиспользуемые типы)
Привязка к должности создателя
Типы операций могут создавать только руководители или администраторы, а мастера используют их при записи операций.

2. OperationRecord (Запись операции)
Документ, фиксирующий выполненную технологическую операцию:
Тип операции (из справочника)
Дата и время выполнения (можно указать прошедшую дату)
Склад (где выполнялась операция)
Материал (с которым работали)
Количество в трёх единицах измерения:
Штуки (quantity)
Погонные метры (square_meters)
Кубические метры (cubic_meters)
Создатель и его должность

### Учёт операций
Запись выполненных операций с указанием количества
Гибкая система единиц измерения (можно указать любую комбинацию)
Фильтрация по:
    Типу операции
    Складу
    Материалу
    Диапазону дат
    Наличию измерений (с площадью, с объёмом, с обоими)
Поиск по материалу
Детальный просмотр каждой операции
Редактирование и удаление записей

### Статистика
Общее количество операций
Суммарное количество по трём единицам измерения
Статистика по типам операций (количество и объёмы)

## Ролевая модель
Действие	                    Руководитель	    Мастер
Создание типов операций	        Да	                Нет
Редактирование типов операций	Да	                Нет
Активация/деактивация типов	    Да	                Нет
Запись операций	                Да	                Да (на своих складах)
Редактирование записей	        Да	                Да (на своих складах)
Удаление записей	            Да	                Да (на своих складах)
Просмотр статистики	            Да	                Свои операции

## Технические особенности
Связь с inventory через сервисный слой для получения складов пользователя
Гибкая валидация — можно указать количество в любых единицах
Три знака после запятой для всех количественных значений
Выделение строк в таблицах
Автоматическая фильтрация при изменении параметров

## Интеграция с другими приложениями
core — использует справочник складов (Warehouse)
forestry — использует справочник материалов (Material)
inventory — использует сервис для определения складов пользователя
