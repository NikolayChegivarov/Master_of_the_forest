
# Хозяин Леса   
### Система управления лесным хозяйством  

___Мастер Леса — это корпоративная ERP-система для управления лесным хозяйством и складским учётом.   
Разработана для автоматизации ключевых бизнес-процессов лесопромышленных предприятий:   
учёта лесных ресурсов, движения материалов, кадрового администрирования и производственных операций.
Система построена на ролевой модели доступа: каждая должность (мастер леса, руководитель, бухгалтер,   
механик и др.) получает доступ ровно к тем функциям, которые необходимы для выполнения своих задач.  
Руководитель имеет возможность временно переключаться на интерфейсы подчинённых для контроля и помощи.___

## Ключевые функции
### 📋 Справочники и управление предприятием
Должности — гибкая система ролей и разграничения прав
Склады, транспорт, бригады, контрагенты — единая база всех ключевых сущностей
Сотрудники — кадровый учёт с привязкой к должностям и складам
Автоматическая синхронизация — сотрудники с руководящими должностями  
автоматически получают доступ к системе
### 🌲 Лесное хозяйство
Лесничества — управление территориальными единицами
Лесосеки — учёт участков с привязкой к кварталам и выделам
Материалы на лесосеках — отслеживание объёмов древесины на каждом участке
Справочник материалов — единая номенклатура (древесина, ГСМ, запчасти)
### 📦 Складской учёт
Места хранения — склады, транспорт, бригады, контрагенты
Остатки материалов — актуальные остатки в трёх единицах измерения (шт, м.п., м³)
Движения материалов — перемещение, отправление, реализация, списание
Конвертация древесины — переработка (бревна → доски, брус)
Поступления материалов — приход с возможностью указания даты и источника
Автоматическое создание мест хранения — каждый склад, ТС, бригада и контрагент автоматически   
становятся местом хранения
### ⚙️ Техпроцессы
Типы операций — настройка справочника технологических процессов
Учёт операций — фиксация выполненных работ с указанием объёмов (шт, м.п., м³)
### 👥 Учёт рабочего времени
Записи рабочего времени — фиксация отработанных часов
Отчёты по сотрудникам — детализация по дням
Отчёты по складам — группировка по сотрудникам  
### 🛡️ Безопасность и ролевая модель
Должность	    Доступные функции
Руководитель	Полный доступ ко всем разделам, переключение на интерфейсы подчинённых
Бухгалтер	    Остатки и движения материалов (всех должностей)
Мастер леса	    Лесничества, лесосеки, материалы, склады, движения
Мастер ЛПЦ	    Лесоперерабатывающий цех
Мастер ДОЦ	    Деревообрабатывающий цех
Мастер ЖД    	Железнодорожный транспорт
Механик      	Транспортные средства

### Целевая аудитория

## ИНСТРУКЦИИ ДЛЯ ПОЛЬЗОВАТЕЛЕЙ
###  Сотрудники
Через этот интерфейс создаются только рядовые сотрудники для учета 
рабочего времени и так же для указания в поле водитель.
Руководящие должности с паролем и доступом создаются только через админку - создать сотрудника
(Галочка - есть доступ появляется после того как сотрудник авторизуется на сервисе). 
Что бы удалить доступ к сайту надо убрать галочки активности через админку в поле users.
Что бы сотрудник больше не выпадал в списках сайта необходимо деактивировать сотрудника через  
web интерфейс или убрать активность через админку в поле сотрудники.
Руководитель реализация.
###  Движение материалов
Заходя в интерфейс должности вы получаете права должности в интерфейс которой входите.
Существует 4 типа движения материалов:
ПЕРЕМЕЩЕНИЕ  
"откуда" только свои места хранения  
"куда" только свои места хранения  
Поле "цена" неактивно
ОТПРАВЛЕНИЕ  
"откуда" только свои места хранения  
"куда" только чужие места хранения  
Поле "цена" неактивно
РЕАЛИЗАЦИЯ  
"откуда" все места хранения  
"куда" только контрагенты  
Поле "цена" активно
СПИСАНИЕ  
"откуда" только свои места хранения склады  
"куда" только места хранения склады, бригады и авто  
"МАТЕРИАЛЫ" только ГСМ и запчасти  
Поле "цена", "водитель", "транспортное средство" неактивны
ПОСТУПЛЕНИЕ
"откуда" только контрагенты
"куда" любые склады  
"МАТЕРИАЛЫ" все
Поле "цена" неактивно

### Места хранения
Местами хранения являются объекты, где физически размещаются материалы (склады), куда списываются материалы 
('транспортные средства', 'бригады') а так же куда реализуются материалы ('контрагенты').
Каждое место хранения имеет владельца — пользователя (должность), который его создал и управляет остатками
материалов на нём.

### Остатки материалов
Видеть можно только остатки находящиеся на своих местах хранения.  
Остатки нельзя удалить или редактировать на прямую, только через документ  
поступление, перемещение, отправление, списание.

### Приходовать материалы
Создавать новые остатки можно только на свои места хранения.
Это гарантирует, что вы управляете только теми запасами, за которые отвечаете.

Дату поступления по умолчанию стоит "сегодня". Выставить дату можно в ручную но не более 7 дней назад,  
так же нельзя выбрать дату, которая не наступила. Приходовать и удалять можно в течении 5 дней. 
Источник поступления позволяет выбрать контрагента (необязательное заполнение)
Место хранения (место хранения Склад) можно выбрать только места хранения своей должности.
Материал можно выбрать любые. 

###  Журнал поступлений
На каждом поступлении кнопка просмотр, кнопка редактировать (активна 5 дней после создания ПОСТУПЛЕНИЯ), 
кнопка удаления (активна 5 дней после создания). 
Поступление напрямую связанно с остатками и редактирование количества, склада поступления ведет к изминениям в остатках.
При редактировании поступления происходит проверка на остаток материала на указанном складе, 
так как указанное количество материалов может быть уже перемещено другим документом.
